# 模块管理

页面 `/p/modules` 支持通过 Web 启用和禁用 9 个业务模块。配置存储在 MySQL，保存成功后立即影响页面、接口和后台任务，无需重启。

## 范围

| 模块 | 禁用范围 |
| --- | --- |
| UPS / ESXi 状态 | 页面、业务接口、采样、告警、历史清理 |
| 证书签发 | 页面、业务接口、签发、续期、自动部署和部署重试 |
| CAS 证书 | 库存查看、删除、从此模块发起的 CDN 证书部署 |
| CDN 域名 | 域名查询页面和查询接口 |
| 生日 / 事项提醒 | 页面、记录管理、自动提醒和手动推送 |
| 短信转发 | 页面、设备管理、短信查询和发送；不改变手机端 SmsForwarder |
| 12306Bypass 中转 | webhook 接收处理及通知转发 |

任务调度、通知渠道、模块管理、健康检查、日志与数据库保持运行。桌面侧栏、手机切换和快捷搜索中的禁用模块消失；当前页面或旧链接自动跳转到模块管理。全部业务禁用时，首页也进入模块管理。

不修改设备、域名、部署配置和通知绑定的原有启用状态，不删除凭证、证书或历史数据。UPS/ESXi 历史清理也暂停；重新启用后的下一次清理仍按原保留天数执行。

CAS 与 CDN 按操作归属控制：CDN 域名查询归 `cdnops`；CAS 页面的 CDN 部署归 `certstore`；ACME 上传 CAS 使用自己的目标凭证，归 `acme`。

## 生效与恢复

- 保存后，新业务请求返回 HTTP 403、`code: MODULE_DISABLED`。管理页面和接口始终可用。
- 定时和手动调度使用同一开关。暂停不覆盖最近执行结果，也不改变连续失败次数；不产生所属任务的新失败告警。
- 已开始的请求、远程部署和正在发送的通知允许收尾。管理页显示仍有操作正在收尾。
- 业务 SSE 随禁用结束。全局模块 SSE 向所有标签页推送全量状态，前端另有定期拉取和恢复焦点时的校正。
- ACME 排队任务真正执行前再次检查提交时的启用周期；快速禁用再启用不会放行旧队列。任务标为 `paused`，保留尝试次数，可在启用后手动重试。
- 暂停的吊销任务需要在域名页面核对当前证书后重新发起，避免按旧任务误吊销另一张证书。
- 正在签发的证书可以完成落盘；原启用周期结束后不再新启动自动部署。正在部署的任务若失败且原启用周期已经结束，则暂停后续重试。
- 原本处于定时待重试状态、尚未被拉起的部署保留原状态；启用后按下一轮扫描恢复。最近一次签发/续期暂停的域名在 12 小时宽限期内不自动重复签发，留给用户手动重试或主动重新签发；超过宽限期后自动续期照常执行（避免一次重启让域名永久跳过续期），完成新签发后旧暂停记录同样不再阻止续期。
- 进程重启后遗留的 `pending` / `running` ACME 任务标为暂停，提示核对实际结果后手动重试。
- UPS/ESXi 从下一次采样恢复并重建告警基线，不补采停用期间的数据。UPS 当前的电池/低电异常仍会报告；ESXi 超阈项重新累计。

## 结构与 API

`internal/modulecontrol` 集中登记模块及任务，管理持久化配置、任务准入和订阅。配置更新与准入共用互斥锁，数据库提交成功后更新内存状态；异步任务持有提交时的 Ticket，在真正开始时校验版本。

`module_setting` 保存 `module_key`、`enabled`、`version`、`updated_at`。初次初始化启用现有业务，重复初始化不覆盖已保存配置；读取失败停止启动，保存失败保持原状态。过期配置更新返回 409。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system/modules` | 全量模块状态、配置版本、运行中操作数 |
| PUT | `/api/system/modules/:key` | `{ "enabled": false, "version": 1 }`，返回生效后的全量状态 |
| GET | `/api/system/modules/stream` | SSE `modules` 事件，初次连接及状态改变时发送全量数据 |

调度列表增加 `module`、`paused`；暂停任务无下次执行时间，手动按钮禁用。前端按进程实例标识和事件版本处理状态，避免同一实例的旧响应覆盖新状态。

本实现面向单活动进程。多个进程共享数据库时需要另行增加配置广播和任务协调。数据库地址、监听端口等启动参数仍需重启，本版不提供任意 `.env` 热重载。

## 迁移与验证

AutoMigrate 创建表并初始化缺失模块；也提供幂等脚本 `sql/19_module_settings.sql`，重复执行不覆盖现有开关。

验证涵盖持久化恢复、保存失败、版本冲突、接口拦截、调度暂停、业务 SSE 结束、旧队列失效、运行中部署收尾、前端导航及多标签页同步。

ACME 数据库集成测试通过 `HOMER_TEST_MYSQL_DSN` 显式启用，并限定数据库名为 `homer_modules_test`。使用独立临时 MySQL，禁止指向实际业务库。
